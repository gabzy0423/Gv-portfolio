# GV Portfolio

Shared language for the portfolio's project showcase and navigation experience.

## Project Showcase

**Interactive project card**:
A clickable project preview that gives visual feedback on hover or keyboard focus and opens the project's detail page.
_Avoid_: Expandable card, modal preview

**Project detail page**:
The dedicated page containing the complete context, description, technologies, and outcome for one project.
_Avoid_: Project modal, project popup
